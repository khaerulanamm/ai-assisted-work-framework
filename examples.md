# Example: Using the Framework

Manager asks: “Create a PRD for an inventory monitoring application.”

1. Open `02-Product/PRD.md`.
2. Fill `12-Shared/CONTEXT.md` with known project information.
3. Provide any company PRD template/SOP.
4. Give the framework + context + company material to AI.
5. Ask AI to generate the PRD while separating facts, assumptions, recommendations, risks, and open questions.
6. Run `12-Shared/QUALITY_GATE.md`.
7. Adapt to the company's final format and obtain approval.

The same pattern applies to BRD, architecture, data model, document processing, application testing, SIT, UAT, deployment, and review.
