# AI-Assisted Professional Work Framework

A reusable, standards-informed framework for producing professional work artifacts with AI.

## Purpose
Use this repository when a manager, stakeholder, client, or team asks you to produce or solve something.

It provides reusable AI work instructions, professional artifact structures, reasoning rules, quality gates, and company-tailoring rules.

It is NOT a company standard and does NOT automatically make an output compliant with an industry standard.

## How to use
1. Identify the work artifact you need.
2. Open the relevant `.md` framework.
3. Copy the full framework into your AI tool.
4. Provide the real business/project context and any company template/SOP.
5. Ask AI to execute the framework.
6. Review assumptions, gaps, risks, and recommendations.
7. Validate against actual company/project requirements.
8. Save the final deliverable in the actual project workspace.

## Priority
1. Law/regulation/contract
2. Company policy/SOP/template/governance
3. Project requirements and stakeholder decisions
4. Applicable external standards/professional practices
5. This personal framework
6. AI recommendations

## Structure
- `01-Business` — BRD and business process
- `02-Product` — PRD and user stories
- `03-Requirements` — requirements engineering
- `04-Design` — system design
- `05-Architecture` — architecture and ADR
- `06-Data` — data requirements, model, quality
- `07-Document-Processing` — mixed-document extraction
- `08-Development` — technical specification and code review
- `09-Testing` — application, integration, SIT, UAT, regression
- `10-Deployment` — deployment, release, rollback
- `11-Review` — decisions, issues, project review
- `12-Shared` — common AI rules/context/quality gate
- `references` — standards/practice register

## Core rule
**Context changes. Framework remains reusable.**

Never treat AI output as final merely because it was generated by AI.
